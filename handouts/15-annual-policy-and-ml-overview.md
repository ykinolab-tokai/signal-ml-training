### 4. 教師あり学習の流れ

#### データ・モデル・パラメータ

入力 $x$ と，その入力に対する正解 $y$ の組を集めたデータ $(x_1, y_1), \ldots, (x_N, y_N)$ から，入力から正解を予測する規則を求めることを **教師あり学習 (supervised learning)** という。
正解が実数値のものを **回帰 (regression)**，正解がクラス（「音声」と「非音声」のような種類）のものを **分類 (classification)** という。
回帰と分類は第19回で扱う。

予測に使う関数 $f(x;\theta)$ を **モデル (model)** という。
$\theta$ はモデルの形を決める値で，**パラメータ (parameter)** と呼ばれる。
例えば，直線のモデル

$$
f(x;a,b) = ax + b
$$

のパラメータは，傾き $a$ と切片 $b$ の 2 つである。
同じ形のモデルでも，パラメータの値によって予測は変わる。

#### 損失関数

予測と正解のずれを 1 つの数値で表す関数を **損失関数 (loss function)** という。
回帰でよく使う損失関数は，次の **平均二乗誤差 (mean squared error, MSE)** である。

$$
L(\theta) = \frac{1}{N}\sum_{i=1}^{N}\bigl(f(x_i;\theta) - y_i\bigr)^2
$$

予測が正解に近いほど $L(\theta)$ は小さくなり，すべての予測が正解と一致するときに 0 になる。
データを固定すると，損失はパラメータの関数になり，パラメータの良し悪しを比べる基準になる。

#### 最適化

損失が最小となるパラメータを探すことを **最適化 (optimization)** という。
データを使ってパラメータを決めることを **学習 (training)** という。
最も単純な最適化の方法は，パラメータの候補の値をすべて調べ，損失が最小となるものを選ぶ方法であり，**グリッドサーチ (grid search)** という。
次の例では，原点を通る直線のモデル $f(x;a) = ax$ のパラメータ $a$ を，0 から 5 まで 0.1 刻みで調べる。

```python
rng = np.random.default_rng(1)
x = rng.uniform(-1, 1, size=20)
y = 3 * x + rng.normal(0, 0.2, size=20)

def mse(y_pred, y_true):
    return np.mean((y_pred - y_true)**2)

print(mse(2 * x, y))  # 約 0.407
print(mse(3 * x, y))  # 約 0.056

a_values = np.linspace(0, 5, 51)
losses = np.array([mse(a * x, y) for a in a_values])
best = np.argmin(losses)
print(losses.shape)                  # (51,)
print(a_values[best], losses[best])  # 3.1 約 0.052

fig, ax = plt.subplots()
ax.plot(a_values, losses)
ax.scatter(a_values[best], losses[best])
ax.set_xlabel("a")
ax.set_ylabel("MSE")
ax.grid(True)
fig.savefig(figure_dir / "session15_example_grid_search.png")
plt.show()
plt.close(fig)
```

データは，$y = 3x$ に平均 0，標準偏差 0.2 の正規乱数（第6回）を加えて作っている。
`mse` は，予測の配列と正解の配列から平均二乗誤差を計算する関数である。
`[mse(a * x, y) for a in a_values]` は，51 個の候補のそれぞれについて損失を計算したリストを作る（第2回のリスト内包表記）。
損失が最小となる $a$ は 3.1 であり，データを作った式の係数 3 に近い。
ちょうど 3 にならないのは，データに乱数による誤差が含まれており，有限個のデータから値を決めているためである。
グリッドサーチは単純だが，パラメータの数が増えると，調べる組合せの数が急激に増える。
第16回では，損失の勾配を使って効率よくパラメータを更新する方法を扱う。

#### 評価

学習したモデルの良し悪しは，学習に使っていないデータで確かめる。
これを **評価 (evaluation)** という。
学習に使ったデータで損失が小さくても，新しいデータでよく当たるとは限らない。
新しいデータに対してもよく予測できる性質を **汎化 (generalization)** という。

以上の 5 つの要素を，直線の当てはめの例でまとめると次のようになる。

| 要素 | 意味 | 直線の当てはめでの例 |
| --- | --- | --- |
| データ | 入力と正解の組 | $(x_i, y_i)$，$i = 1, \ldots, N$ |
| モデル | パラメータを持つ予測の関数 | $f(x;a,b) = ax+b$ |
| 損失 | 予測と正解のずれ | 平均二乗誤差 |
| 最適化 | 損失が最小となるパラメータを探す | グリッドサーチ（第16回では勾配降下法） |
| 評価 | 学習に使っていないデータで確かめる | test のデータでの平均二乗誤差 |

### 5. train・validation・test

#### データの分割

評価のため，手元のデータを役割の異なる 3 つに分ける。

| 名前 | 役割 |
| --- | --- |
| **train** | パラメータを学習する |
| **validation** | モデルの形や学習の設定を選ぶ |
| **test** | 最後に 1 回だけ，選んだモデルの性能を評価する |

データが測定した順に並んでいる場合のように，並び方に偏りがあることもある。
このため，分割の前にデータの順番をランダムに並べ替える。
第6回で扱った `rng.permutation(n)` は，`0` から `n - 1` までの整数をランダムに並べ替えた配列を返す。

```python
rng = np.random.default_rng(2)
indices = rng.permutation(50)
train_idx = indices[:30]
val_idx = indices[30:40]
test_idx = indices[40:]
print(indices[:8])                                  # [ 6 40 33 38  7 46 28 45]
print(len(train_idx), len(val_idx), len(test_idx))  # 30 10 10
print(np.intersect1d(train_idx, test_idx))          # []
```

並べ替えた添字を先頭から順に切り分けると，50 個のデータを重複なく 30 個，10 個，10 個に分けられる。
`np.intersect1d` は 2 つの配列に共通する要素を返す関数であり，ここでは train と test に同じデータが含まれていないことを確かめている。
データの配列 `x` から train のデータを取り出すには，`x[train_idx]` のように添字の配列で選択する（第3回の整数配列による選択）。
乱数のシードを固定しておくと，同じ分割を再現できる。

#### モデルの選択と過学習

モデルには，学習で決めるパラメータのほかに，学習の前に人が決める設定がある。
例えば，$d$ 次多項式のモデル

$$
f(x;\boldsymbol{w}) = w_d x^d + w_{d-1} x^{d-1} + \cdots + w_1 x + w_0
$$

では，学習で係数 $w_0, \ldots, w_d$ を決める前に，次数 $d$ を決める必要がある。
このような設定を **ハイパーパラメータ (hyperparameter)** という。
NumPy の `np.polyfit(x, y, d)` は，平均二乗誤差が最小となる $d$ 次多項式の係数を，次数の高い順に並べて返す（計算の仕組みは第16回の最小二乗法で扱う）。
`np.polyval(coef, x)` は，係数 `coef` の多項式の値を `x` の各要素について計算する。

```python
x = np.linspace(-1, 1, 11)
y = 2 * x**2 - x + 0.5
coef = np.polyfit(x, y, 2)
print(coef)                                    # [ 2.  -1.   0.5]
print(np.polyval(coef, np.array([0.0, 1.0])))  # [0.5 1.5]
```

この例のデータは誤差を含まない 2 次関数から作ったため，求めた係数は元の式の係数 $2, -1, 0.5$ と一致する。

次数を上げると，モデルで表せる曲線の種類が増えるため，train の平均二乗誤差は小さくなる（大きくはならない）。
しかし，train のデータに含まれる誤差まで再現するように曲線が曲がると，新しいデータに対する誤差はかえって大きくなる。
このように，train のデータには合うが新しいデータには合わない状態を **過学習 (overfitting)** という。
そこで，次数のようなハイパーパラメータは，train で学習した各モデルの validation での誤差を比べて選ぶ。

#### test のデータの扱い

test のデータは，モデルとハイパーパラメータをすべて決めた後に，最後に 1 回だけ使う。
test の結果を見てハイパーパラメータを選び直すと，test のデータに合わせて選んだことになり，test での誤差が，新しいデータに対する誤差より小さく見積もられる。
第13回のプロジェクトで，しきい値などを train や dev で決め，test では固定したのと同じ考え方である。
第13回の dev は，validation と同じ役割である。
