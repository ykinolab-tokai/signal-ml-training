# 第15回 年間方針と機械学習の流れ

## この回の目標

年間方針と自分の役割を確認し，教師あり学習の流れ（データ，モデル，損失，最適化，評価）を説明できる。

## 解説
- この回の `提出リポジトリ` は，第1回で作成した自分の作業リポジトリ（PC上では `~/workspace/signal-ml-work`）を指す。新たな提出用リポジトリは作らない。作成・取得と保存先は [共通手順](README.md#作業場所と保存先)，生成AIを使う場面は [READMEの時間配分](../README.md#4-各回の標準的な時間配分)を確認する。
- このリポジトリの `README.md` は年間方針の source of truth であり、学年ごとの責務、評価、提出先、生成 AI 方針は README を基準に読む。handout ごとのローカルな慣習よりも README を優先する。
- 共通リポジトリは教材、見本コード、共通資産を置く場所で、通常提出の置き場ではない。通常提出は各自の `提出リポジトリ` に残す。両者を混ぜると、教材更新と個人提出の履歴が衝突する。
- 役割分担では、B4 は extension を実装して後輩の視界を広げる側、M は品質確認と支援設計を担う側になる。単に「担当回を書く」だけでなく、自分がどこで価値を出すかまで決めると後続回が進めやすい。
- 第15回から第28回では，第14回までの内容だけを前提に，PyTorch による機械学習プロジェクトを進められるようになることを目指す。最適化（第16回）と推定（第18回）の数学は，それを使う回の直前に扱う。
- 教師あり学習では，入力 $x$ と正解 $y$ の組からなるデータを使い，パラメータ $\theta$ を持つモデル $f(x;\theta)$ の出力が正解に近づくように $\theta$ を決める。出力と正解のずれを数値で表す関数を **損失関数 (loss function)** といい，損失を小さくする $\theta$ を探すことを **学習 (training)** という。
- 学習に使ったデータで損失が小さくても，新しいデータでよく当たるとは限らない。そこで，データを学習用（train），設定の選択用（validation），最終評価用（test）に分ける。第13回のプロジェクトで，しきい値などを train や dev で決め，test で評価したのと同じ考え方である。

## 演習

作業場所・保存先・説明の残し方は [共通手順](README.md#作業場所と保存先) に従ってください。以下の相対パスは，自分の作業リポジトリのルートを基準とします。

### 基礎レベル
1. `README.md` を読み、年間 28 回の構成、学年ごとの責務、通常提出と PR 練習の違い、生成 AI 利用時の申告ルールを確認してください。
2. `session15_role_plan.md` を作成し、`## 自分の学年`, `## 前期で担当する回`, `## 後期で担う支援役割`, `## 今年度の重点` の 4 見出しを書いてください。各見出しには、README の記述に基づく自分の役割と判断理由を 1〜3 行で書いてください。
3. `session15_ai_ops_checklist.md` を作成し、`## 共通リポジトリの役割`, `## 提出リポジトリの役割`, `## 生成AI利用時の申告項目`, `## 今年気をつける運用ルール` の 4 見出しを書いてください。共通リポジトリと提出リポジトリを混同すると何が困るかも 1 例入れてください。
4. `session15_line_fit.py` を作成し，教師あり学習の流れを確かめてください。`rng = np.random.default_rng(0)` を使い，$[0, 1]$ の一様乱数 $x$ を 40 個と，$y = 2x + 1 + \varepsilon$（$\varepsilon$ は平均 0，標準偏差 0.1 の正規乱数）を作ります。前半 30 個を train，残り 10 個を test とします。モデルを $f(x) = ax + b$ とし，$a$ と $b$ をそれぞれ $0$ から $4$ まで $0.1$ 刻みで動かして，train の平均二乗誤差が最小となる $(a, b)$ を探してください。求めた $(a, b)$ での train と test の平均二乗誤差を表示し，データ，モデル，損失，最適化，評価がコードのどこに当たるかをコメントに書いてください。

### 発展レベル
1. B4 は `session15_role_plan.md` に `## extension 候補` を追加し、試したい発展課題 1 件と、その前に後輩が理解しているべき前提 2 項目を書いてください。
2. M は `session15_role_plan.md` に `## 介入条件` を追加し、mentor/reviewer として介入すべき条件を 3 項目書いてください。各項目には、介入が早すぎる場合と遅すぎる場合の問題を 1 行ずつ添えてください。
3. 生成 AI 利用申告が必要な場面を 2 例、不要な場面を 1 例書き、違いを `再現性` と `責任の所在` の観点から説明してください。
4. 基礎第4問で平均二乗誤差を計算した回数を数えてください。パラメータが 10 個あり，それぞれを同じように 41 通り調べる場合の回数も計算し，第16回で扱う勾配を使う方法が必要になる理由を説明してください。

- `session15_line_fit.py` が train と test の平均二乗誤差を表示し，データ，モデル，損失，最適化，評価に当たる箇所がコメントで示されている。
- B4 は extension 候補と前提条件、M は介入条件と理由を書いている。
- リポジトリの使い分けと AI 申告の違いが、単なる用語説明ではなく運用上の理由まで含めて書かれている。
