# 第05回 線形代数

## この回の目標

- ベクトルと行列の和，内積，行列積を NumPy で計算する。
- ノルム，射影，線形変換の意味を図と数値で確認する。
- 逆行列と連立一次方程式の関係を確認する。
- shape を見ながら，計算可能な行列演算を判断する。

## 解説
- ベクトルは数値を並べたもの，行列はベクトルを変換するものとして扱える。NumPy では shape を確認しながら計算することが重要である。
- 内積は2つのベクトルの向きの近さを測る計算として見られる。ノルムはベクトルの長さを表す。
- 射影は，ある方向に沿った成分を取り出す操作である。残差が射影先の方向と直交することを確認すると意味が分かりやすい。
- 逆行列は，線形変換を元に戻す行列である。ただし，すべての行列に逆行列があるわけではない。

### 基礎レベル
1. `A=np.arange(6).reshape(2,3)`，`B=np.arange(6).reshape(3,2)`，`v=np.array([1,2,3])` とする。`A@B`，`B@A`，`A@v`，`B@v`，`A+B` の可否と結果のshapeを予想する。可能なものを計算し，不可能なものはどの次元が合わないか説明する。
2. `u=np.array([1,2])`，`v=np.array([3,-1])` の内積・ノルムを計算する。`v` の `u` 方向への射影 `p=(u@v)/(u@u)*u` を手計算してから実装し，`u@(v-p)` が0に近いことを確かめる。
3. `C=np.array([[2,1],[1,3]])`，`b=np.array([1,-2])` として `C@x=b` を `np.linalg.solve` で解く。残差 `C@x-b` と，`np.linalg.inv(C)@b` との差を確認する。浮動小数点の比較には `np.allclose` を用いる。
4. shapeの予測表，射影の手計算と結果，連立方程式の残差をレポートへまとめる。

### 発展レベル（1項目を選択）
1. `C` と `D=np.array([[0,1],[2,1]])` で `C@D` と `D@C` を比較する。
2. 2次元格子の回転・拡大縮小・せん断から1つ選んで描き，長さ・角度・平行性を説明する。
3. `S=np.array([[1,2],[2,4]])` の行列式とランクを調べ，逆行列がない理由を説明する。ここでのランクは配列の `ndim` とは異なる。
4. `C=np.array([[1,1],[1,1.0001]])`，`b=np.array([2,2.0001])` と，`b[1]` に `1e-4` を加えた場合の解を比較する。条件数 `np.linalg.cond(C)` と解の変化を記録する。
5. 3次元の `u=np.array([1,1,1])`，`v=np.array([1,0,-1])` でも同じ射影式を確認する。

## 確認ポイント
- 演算可能性を値の計算前にshapeから判断できる。
- 射影の残差は射影先のベクトルと直交し，連立方程式の残差は0に近い。
- 手計算・数値比較・レポートが対応している。
