# 第04回 微分と積分

## この回の目標

- 傾きと数値微分を，式と計算の両方で確認する。
- 偏微分と勾配を NumPy で近似する。
- 関数の極値を，グラフと勾配の観点から確認する。
- 区分求積法，定積分，数値積分を実装する。

## 解説
- 微分は，入力を少し動かしたときの出力の変化率を表す。数値微分では，小さな `h` を使って差分から傾きを近似する。
- 多変数関数では，1つの変数だけを動かした変化率を偏微分と呼ぶ。各変数についての偏微分を並べたものが勾配である。
- 関数の極値では，勾配が 0 に近くなることが多い。ただし，数値計算では刻み幅や探索範囲によって近似結果が変わる。
- 積分は，小さな区間の面積を足し合わせる操作として近似できる。区分求積法や台形公式を実装すると，定積分を数値で扱える。

### 基礎レベル
1. `f(x)=x**2+3*x+1` の `f'(1)=5` を確認する。前進差分 `(f(x+h)-f(x))/h` と中心差分 `(f(x+h)-f(x-h))/(2*h)` を `h=1e-1, 1e-3` で比較し，絶対誤差を表にする。
2. `q(x,y)=x**2+x*y+y**2` の点 `(1,2)` で，偏微分の解析値 `(4,5)` と中心差分（`h=1e-3`）を比較する。
3. `g(x)=(x-2)**2+1` に対し，初期値 `x0=0`，学習率 `eta=0.1` とする。更新式 `x_new=x-eta*2*(x-2)` の1回目を手計算してから，10回の更新を実装する。更新前後の `x` と `g(x)` を記録する。
4. `x**2` の区間 `[0,1]` を4等分し，左端の値を使う長方形の面積の和を手計算する。同じ規則を分割数10，100で実装し，真値 `1/3` との誤差を比べる。分割点数と区間数を区別する。

### 発展レベル（1項目を選択）
1. 数値微分の `h` を `1e-1` から `1e-12` まで変え，丸め誤差で改善しなくなる場合を調べる。
2. `q` の等高線と点 `(1,2)` の勾配を図示し，勾配が向く方向を説明する。
3. 勾配降下の学習率を0.01，0.1，1.0で比較する。収束・振動の違いを記録する。
4. `sin(x)` の `[0,pi]` の積分を `np.trapezoid(y, x)` で近似し，分割数10，100，1000と真値2から誤差曲線を作る。
5. `x**4-3*x**2+1` を `[-2,2]` の格子で調べ，極小点の候補を比較する。

## 確認ポイント
- 中心差分では分母が `2*h` で，解析値との誤差を比較している。
- 勾配降下の1更新と長方形4個の面積計算が，実装と対応している。
- 反復条件・分割数と結果を記録し，発展課題の全実施を完了条件にしていない。
