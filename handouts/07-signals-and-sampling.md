### 1. 信号とは

**信号 (signal)** とは，音や光のように情報を伝える物理量の変化を，時間などの量の関数として表したものである。
信号は，1 つ以上の独立変数を持つ関数・数列・ベクトルとして表される。
例えば，マイクで観測した音圧は時間の関数であり，画像の画素値は縦と横の位置の関数である（第12回）。
物理的に観測される信号は実数値であることが多いが，理論的には複素数値の信号を考えるほうが便利である。
そこで，これ以降は特に指定のない限り，信号は複素数の値をとるものとする。
また，以下では，時間を独立変数とする信号を考える。

#### 連続時間信号

任意の時刻 $t \in \mathbb{R}$ に対して値が定義される信号を **連続時間信号 (continuous-time signal)** といい，丸括弧を使って $x(t)$ と表す。
マイクの前の空気の圧力の変化のように，自然界の物理量は連続時間信号として考えることが多い。

#### 離散時間信号

とびとびの時刻，すなわち整数 $n \in \mathbb{Z}$ に対して値が定義される信号を **離散時間信号 (discrete-time signal)** といい，角括弧を使って $x[n]$ と表す。
$n$ はサンプル番号であり，秒などの単位を持つ時刻そのものではない。
$x[n]$ を要素とするベクトル $\boldsymbol{x} = (\cdots, x[n-1], x[n], x[n+1], \cdots)^\top$ として表すこともある。
コンピュータで扱えるのは有限個の値だけなので，NumPy では $x[0], x[1], \ldots, x[N-1]$ の $N$ 個の値を，長さ $N$ の 1 次元配列 `x` で表す。
配列の要素 `x[i]` は $x[i]$ に対応し，$n<0$ や $n \ge N$ の値は配列に含まれない。

#### 正弦波信号と周期信号

実用上重要な信号の多くは，正弦波の重ね合わせ（和）の形に分解できる（第8回の Fourier 変換）。
このため，信号処理においては正弦波が非常に重要である。
連続時間の **正弦波信号 (sinusoidal signal)** は次の式で表される。

$$
x(t) = A \sin(2\pi F t + \phi) = A \sin(\Omega t + \phi)
$$

- $A$：**振幅 (amplitude)**
- $F$：**周波数 (frequency)** [Hz]。1 秒あたりに同じ波形を繰り返す回数を表す。
- $T = 1 / F$：**周期 (period)** [s]
- $\phi$：**位相 (phase)** [rad]。$t = 0$ における $\sin$ の引数の値であり，初期位相とも呼ぶ。
- $\Omega = 2\pi F$：**角周波数 (angular frequency)** [rad/s]

すべての $t$ について $x(t + T) = x(t)$ を満たす正の定数 $T$ が存在する信号を **周期信号 (periodic signal)** といい，$T$ をその周期という。
周期 $T$ を持つ信号は，その整数倍 $kT$（$k = 1, 2, \ldots$）も周期として持つ。
周期信号の周期のうち最小のものを **基本周期 (fundamental period)** という。
正弦波信号の基本周期は $T = 1/F$ である。
離散時間信号では，すべての $n$ について $x[n + N] = x[n]$ を満たす正の整数 $N$ が存在するとき，周期信号という。
離散時間信号の周期は，整数に限られる。

#### 標本化（サンプリング）

連続時間信号 $x(t)$ の値を一定の時間間隔 $T_s$ ごとに取り出し，離散時間信号 $x[n]$ を得る操作を **標本化 (sampling)** または **サンプリング** という。

$$
x[n] = x(n T_s), \quad n = 0, 1, 2, \ldots
$$

時間間隔 $T_s$ [s] を **サンプリング周期 (sampling period)**，その逆数 $F_s = 1 / T_s$ [Hz] を **サンプリング周波数 (sampling frequency)** という。
$F_s$ は，1 秒あたりに取り出すサンプルの数を表す。
$n$ 番目のサンプルは時刻 $t = nT_s = n / F_s$ に対応するので，同じ配列でも $F_s$ が変われば，表す時間の長さが変わる。
長さ $D$ [s] の区間 $0 \le t < D$ を標本化すると，$DF_s$ が整数の場合，サンプル数は $N = DF_s$ になる。
最後のサンプルの時刻は，$D$ ではなく $D - T_s$ である。

周波数 $F$ の正弦波信号を標本化すると，次の離散時間の正弦波信号が得られる。

$$
x[n] = A \sin(2\pi F n T_s + \phi) = A \sin(\omega n + \phi),
\qquad \omega = 2\pi \frac{F}{F_s} = \Omega T_s
$$

$\omega$ を，離散時間信号の **正規化角周波数 (normalized angular frequency)** という。
単位は rad/sample であり，1 サンプル進むごとに位相が何ラジアン進むかを表す。

#### Python での生成例

```python
def x_cont(t):
    """連続時間信号 x(t) = 0.8 sin(2π·4t + π/6) の時刻 t での値を返す。"""
    return 0.8 * np.sin(2 * np.pi * 4 * t + np.pi / 6)

duration = 0.5            # 信号長 [s]
Fs = 200                  # サンプリング周波数 [Hz]
N = round(duration * Fs)  # サンプル数
n = np.arange(N)          # サンプル番号 0, 1, ..., N - 1
t = n / Fs                # 各サンプルの時刻 n Ts [s]
x = x_cont(t)
print(N, t[:3], t[-1])         # 100 [0.    0.005 0.01 ] 0.495
print(x.shape, round(x[0], 3))  # (100,) 0.4

Fs_low = 40
t_low = np.arange(round(duration * Fs_low)) / Fs_low
x_low = x_cont(t_low)
print(len(t_low), 2 * np.pi * 4 / Fs_low)  # 20 0.6283185307179586

print(int(0.29 * 100), round(0.29 * 100))                    # 28 29
print(len(np.arange(0, 1.1, 1 / 48000)), round(1.1 * 48000))  # 52801 52800

fig, ax = plt.subplots()
ax.plot(t, x, label="Fs = 200 Hz (plot)")
ax.stem(t_low, x_low, linefmt="C1-", markerfmt="C1o", basefmt="k-", label="Fs = 40 Hz (stem)")
ax.set_xlabel("Time [s]")
ax.set_ylabel("Amplitude")
ax.legend()
ax.grid(True)
fig.savefig(figure_dir / "session07_example_sampling.png")
plt.show()
plt.close(fig)
```

`x_cont` は，連続時間信号 $x(t)$ を Python の関数として表したものであり，時刻の配列を渡すと，各時刻での値を同じ形の配列で返す。
同じ関数に異なる時刻の配列を渡せば，同じ連続時間信号を異なるサンプリング周波数で標本化できる。
サンプル数は `round(duration * Fs)` で求めている。
`int(...)` は小数点以下を切り捨てるため，`int(0.29 * 100)` が 29 ではなく 28 になるように，丸め誤差でサンプル数が 1 つ少なくなることがある。
また，時刻の配列を `np.arange(0, duration, 1 / Fs)` のように小数の刻み幅で作ると，丸め誤差で要素数が 1 つ増えることがある。
上の例では，`np.arange(0, 1.1, 1 / 48000)` の要素数が 52800 ではなく 52801 になっている。
このため，整数のサンプル番号 `n` を作ってから，`t = n / Fs` で時刻 $nT_s$ を計算する。
`t[-1]` は 0.5 ではなく 0.495 であり，区間の終点は含まれない。
`Fs_low = 40` の場合，正規化角周波数は $\omega = 2\pi\cdot4/40 \approx 0.628$ rad/sample であり，正弦波の 1 周期を 10 サンプルで表す。

`ax.stem` は，各サンプルの値を縦線と点で描く関数であり，とびとびの時刻にだけ値を持つ離散時間信号を描くのに適している。
`linefmt`，`markerfmt`，`basefmt` は，それぞれ縦線，点，基準線（値 0 の横線）の書式であり，`"C1"` は Matplotlib の既定の色の 2 番目を表す。
`ax.plot` は点の間を線分で結ぶので，サンプリング周波数が十分に高い信号を，連続時間信号の近似として描くのに使う。

### 2. サンプリング定理

ある条件を満たせば，離散時間信号 $x[n]$ から元の連続時間信号 $x(t)$ を完全に復元できる。
この条件を述べる定理を **サンプリング定理 (sampling theorem)** という。

#### サンプリング定理（ナイキスト・シャノンの定理）

連続時間信号 $x(t)$ が $F_{\max}$ [Hz] 以下の周波数成分のみを含む，すなわち $F_{\max}$ [Hz] 以下の周波数を持つ正弦波の和で表せるとする。
このとき，

$$
F_s > 2 F_{\max}
$$

を満たすサンプリング周波数 $F_s$ で信号を標本化すれば，その離散時間信号から元の連続時間信号を完全に復元できる。
復元は，次の式で与えられる。

$$
x(t) = \sum_{n=-\infty}^{\infty} x[n]\, \mathrm{sinc}\left(\frac{t - nT_s}{T_s}\right),
\qquad
\mathrm{sinc}(u) = \frac{\sin(\pi u)}{\pi u}
$$

ここで，$\mathrm{sinc}(0) = 1$ と定める。
$\mathrm{sinc}\left((t - nT_s)/T_s\right)$ は，$t = nT_s$ で 1 となり，他のサンプルの時刻 $t = mT_s$（$m \neq n$）で 0 となる関数である。
したがって，この式は，各サンプルの値を通る滑らかな曲線でサンプルの間を補間している。
NumPy では，$\mathrm{sinc}(u)$ を `np.sinc(u)` で計算できる。
実際の配列は有限個のサンプルしか持たないため，和を有限個で打ち切ることになり，特に配列の両端付近で復元に誤差が生じる。

$F_{\mathrm{Nyq}} = F_s / 2$ を **ナイキスト周波数 (Nyquist frequency)** という。
サンプリング定理の条件は，信号に含まれる周波数がすべてナイキスト周波数より低いことと言い換えられる。
条件の不等号が等号を含まないことに注意する。
例えば，周波数がちょうど $F_s/2$ の正弦波 $\sin(2\pi (F_s/2) t)$ を標本化すると，$\sin(\pi n) = 0$ なので，すべてのサンプルが 0 になる。

#### エイリアシング

$F_{\max} > F_{\mathrm{Nyq}}$ の場合，$F_{\mathrm{Nyq}}$ を超える周波数の成分が，それより低い偽の周波数の成分として観測される。
この現象を **エイリアシング (aliasing)** または **折り返し** という。
周波数 $F$ の余弦波を標本化した $x[n] = \cos(2\pi F n / F_s + \phi)$ を考える。
任意の整数 $m$ に対して $2\pi m n$ は $2\pi$ の整数倍なので，次の 2 つの式が成り立つ。

$$
\cos\left(2\pi \frac{F + mF_s}{F_s} n + \phi\right) = \cos\left(2\pi \frac{F}{F_s} n + \phi\right),
\qquad
\cos\left(2\pi \frac{mF_s - F}{F_s} n + \phi\right) = \cos\left(2\pi \frac{F}{F_s} n - \phi\right)
$$

1 つ目の式は，周波数が $F_s$ の整数倍だけ異なる正弦波は，標本化すると区別できないことを表す。
2 つ目の式は，周波数 $mF_s - F$ の正弦波が，位相の符号を反転した周波数 $F$ の正弦波と同じサンプルを持つことを表す。
特に $m = 1$ とすると，ナイキスト周波数より $\delta$ だけ高い周波数 $F_s/2 + \delta$ の成分は，$F_s/2 - \delta$ の成分として観測される。
周波数の軸の上でナイキスト周波数を境に折り返したように見えることが，「折り返し」という名前の由来である。

```python
Fs = 10                               # サンプリング周波数 [Hz]
n = np.arange(20)                     # 2 秒分のサンプル番号
x3 = np.cos(2 * np.pi * 3 * n / Fs)   # 3 Hz
x13 = np.cos(2 * np.pi * 13 * n / Fs)  # 3 + Fs = 13 Hz
x7 = np.cos(2 * np.pi * 7 * n / Fs)   # Fs - 3 = 7 Hz
print(np.allclose(x3, x13), np.allclose(x3, x7))  # True True
print(np.array_equal(x3, x13))                    # False

t_fine = np.arange(2000) / 1000       # 描画用の細かい時刻 [s]
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(t_fine, np.cos(2 * np.pi * 3 * t_fine), label="3 Hz")
ax.plot(t_fine, np.cos(2 * np.pi * 13 * t_fine), alpha=0.5, label="13 Hz")
ax.stem(n / Fs, x13, linefmt="k-", markerfmt="ko", basefmt="k-", label="13 Hz sampled at 10 Hz")
ax.set_xlabel("Time [s]")
ax.set_ylabel("Amplitude")
ax.legend()
ax.grid(True)
fig.savefig(figure_dir / "session07_example_aliasing.png")
plt.show()
plt.close(fig)
```

$F_s = 10$ Hz のナイキスト周波数は 5 Hz であり，13 Hz と 7 Hz の余弦波はサンプリング定理の条件を満たさない。
13 Hz は 1 つ目の式で $m = 1$ とした場合，7 Hz は 2 つ目の式で $m = 1$，$\phi = 0$ とした場合にあたり，どちらも 3 Hz の余弦波と同じサンプルを持つ。
図では，13 Hz の曲線上のサンプルが，すべて 3 Hz の曲線上にも乗っている。
`np.allclose(a, b)` は，2 つの配列の要素がすべて，丸め誤差程度の差の範囲で等しいかを判定する。
`np.array_equal` は要素が完全に等しいかを判定するため，丸め誤差を含む計算結果の比較では `False` になることがある。
`alpha` は線の不透明度であり，重なった線を見分けやすくするために指定している。

### 3. 信号に対する演算

連続時間信号 $x(t)$ や離散時間信号 $x[n]$ に対して，以下のような基本演算が定義される。
まずそれぞれの演算を式で定義し，最後に有限長の配列での実装方法をまとめて説明する。

#### 時間シフト

信号を時間軸の方向に平行移動する演算を **時間シフト (time shift)** という。

$$
y(t) = x(t - \tau), \quad y[n] = x[n - k]
$$

ここで，$\tau \in \mathbb{R}$ と $k \in \mathbb{Z}$ はシフト量である。
$\tau > 0$（$k > 0$）のとき，$y$ は $x$ を右（時間が進む向き）に移動した信号，すなわち $x$ を遅延させた信号になる。
実際，$y(\tau) = x(0)$ なので，$x$ の時刻 0 の値は，$y$ では時刻 $\tau$ に現れる。
サンプリング周波数 $F_s$ で標本化した信号では，$\tau$ 秒のシフトは $k = \tau F_s$ サンプルのシフトに対応する。

#### 時間反転

時刻 0 を中心として，信号の時間の向きを逆にする演算を **時間反転 (time reversal)** という。

$$
y(t) = x(-t), \quad y[n] = x[-n]
$$

#### 時間伸縮

信号を時間軸の方向に伸び縮みさせる演算を **時間伸縮 (time scaling)** という。

$$
y(t) = x(at), \quad y[n] = x[an]
$$

ここで，$a > 0$ は伸縮の倍率である。
$a > 1$ のとき信号は時間軸の方向に縮み（変化が速くなり），$0 < a < 1$ のとき伸びる（変化が遅くなる）。
離散時間信号では，$an$ が整数でない場合は $x[an] = 0$ とする。
$a$ が 2 以上の整数のとき，$y[n] = x[an]$ は $a$ サンプルごとに 1 つを取り出す **間引き (decimation)** になる。
間引きは，サンプリング周波数を $1/a$ 倍にして標本化し直すことに相当するので，間引いた後の信号ではエイリアシングが起きることがある。

#### 振幅スケーリング・オフセット

$$
y(t) = a \cdot x(t) + b
$$

$a$ を掛ける演算を **振幅スケーリング (amplitude scaling)** といい，$a$ は振幅の倍率を表す。
$a$ が負の数なら，信号の符号も反転する。
$b$ を **オフセット (offset)** といい，振幅の方向への平行移動量を表す。
離散時間信号でも同様に，$y[n] = a \cdot x[n] + b$ と定義する。

#### 信号の加算・乗算

2 つの信号 $x_1$，$x_2$ の **加算 (addition)** と **乗算 (multiplication)** は，同じ時刻の値どうしの和と積で定義する。

$$
y(t) = x_1(t) + x_2(t),\quad y[n] = x_1[n] + x_2[n],
\qquad
y(t) = x_1(t) \cdot x_2(t),\quad y[n] = x_1[n] \cdot x_2[n]
$$

2 つの信号の **内積 (inner product)** は，次のように定義する。

$$
\langle x_1, x_2 \rangle = \int_{-\infty}^{\infty} \overline{x_1(t)}\, x_2(t)\, \mathrm{d}t,
\qquad
\langle x_1, x_2 \rangle = \sum_{n=-\infty}^{\infty} \overline{x_1[n]}\, x_2[n] = \boldsymbol{x}_1^* \boldsymbol{x}_2
$$

ここで，$\overline{z}$ は複素数 $z$ の **複素共役 (complex conjugate)** を表す。
$\boldsymbol{x}^*$ はベクトル $\boldsymbol{x}$ の **複素共役転置 (conjugate transpose)**，すなわち各要素の複素共役をとって転置したものを表す。
実数値の信号では複素共役をとっても値は変わらないので，この内積は第5回の内積 $\boldsymbol{u}^\top\boldsymbol{v}$ と一致する。
複素数値の信号の場合，内積では 1 つ目の信号 $x_1$ の複素共役をとることに注意する。
複素共役をとることで，自分自身との内積 $\langle x, x \rangle = \sum_n |x[n]|^2$ が 0 以上の実数になり，信号の大きさ（エネルギー）を表す。
長さ $N$ の配列で表した信号では，和を $n = 0, 1, \ldots, N-1$ の範囲でとる。
第5回のベクトルと同様に，内積が 0 になる 2 つの信号は直交するという。

#### 配列での実装

```python
x = np.array([3.0, 1.0, 4.0, 1.0, 5.0, 9.0])  # x[0], ..., x[5]
k = 2
x_delay = np.zeros_like(x)
x_delay[k:] = x[:-k]       # y[n] = x[n - 2]，空いた先頭は 0
print(x_delay)             # [0. 0. 3. 1. 4. 1.]
print(np.roll(x, k))       # [5. 9. 3. 1. 4. 1.]
print(x[::-1])             # [9. 5. 1. 4. 1. 3.]
print(x[::2])              # [3. 4. 5.]
print(-2 * x + 0.5)        # [ -5.5  -1.5  -7.5  -1.5  -9.5 -17.5]

x1 = np.array([1 + 1j, 2, -1j])
x2 = np.array([1j, 1, 1])
print(np.vdot(x1, x2))           # (3+2j)
print(np.sum(np.conj(x1) * x2))  # (3+2j)
print(x1 @ x2)                   # (1+0j)
print(np.vdot(x1, x1))           # (7+0j)
```

`np.zeros_like(x)` は，`x` と同じ形と `dtype` で全要素が 0 の配列を返す。
`x_delay[k:] = x[:-k]` は，$y[n] = x[n-k]$ のうち配列に含まれる部分をコピーし，観測を始める前にあたる先頭の $k$ 個を 0 とする遅延である。
`k = 0` のときは `x[:-0]` が空の配列になるため，この書き方は使えないことに注意する。
`np.roll(x, k)` は，要素を右に $k$ 個ずらし，末尾からはみ出した要素を先頭に戻す **巡回シフト (circular shift)** であり，$y[n] = x[(n-k) \bmod N]$ を表す。
巡回シフトの結果が先頭を 0 で埋めた遅延と一致するのは，末尾からはみ出す $k$ 個の要素がすべて 0 の場合だけである。
一方，信号が配列の長さ $N$ の約数を周期として持つ場合，巡回シフトの結果は，配列の外まで同じ周期で続く信号を遅延させたもの（$x(t - \tau)$ を標本化したもの）と一致する。
`x[::-1]` は $y[n] = x[N-1-n]$ を表し，時間反転 $x[-n]$ を $N - 1$ だけ右にシフトして，添字が $0, \ldots, N-1$ の範囲に収まるようにしたものである。
`x[::2]` は，$a = 2$ の時間伸縮（間引き）$y[n] = x[2n]$ である。
信号を `x_cont` のような関数で表している場合は，`x_cont(t - tau)` や `x_cont(-t)` のように，時刻の配列を変えて関数を呼ぶことでも時間シフトや時間反転を計算できる。

`np.vdot(x1, x2)` は，1 つ目の引数の複素共役をとってから対応する要素の積の和を計算するので，内積の定義と一致する。
`np.sum(np.conj(x1) * x2)` も同じ値になる。
一方，`x1 @ x2` や `np.dot(x1, x2)` は複素共役をとらないため，複素数値の信号では内積と異なる値になる。
`np.vdot(x1, x1)` は $\sum_n |x_1[n]|^2 = 2 + 4 + 1 = 7$ であり，実数の値を複素数型 `(7+0j)` で返す。

### 4. 量子化

コンピュータでは，時間だけでなく振幅も有限個の値でしか表せない。
時間と振幅の両方が離散的な信号を **ディジタル信号 (digital signal)** という。
連続的な振幅値を，有限個の代表値のいずれかに対応させることを **量子化 (quantization)** という。

#### 量子化の基本

代表値を区別するために用いるビット数 $B$ を **ビット深度 (bit depth)** という。
$B$ ビットで区別できる代表値の個数は $L = 2^B$ であり，これを **量子化レベル数 (number of quantization levels)** という。
例えば，音楽 CD の音声は 16 ビットで量子化されており，$L = 65536$ 個の代表値を持つ。
隣り合う代表値の間隔 $\Delta$ を **量子化間隔 (quantization step)** といい，量子化間隔が一定である量子化を **一様量子化 (uniform quantization)** という。
振幅の範囲 $[x_{\min}, x_{\max}]$ の両端を代表値に含めて $L$ 個の代表値を等間隔に並べると，量子化間隔と量子化後の値 $\hat{x}$ は次のようになる。

$$
\Delta = \frac{x_{\max} - x_{\min}}{L - 1},
\qquad
\hat{x} = x_{\min} + \Delta \cdot \mathrm{round}\left(\frac{x - x_{\min}}{\Delta}\right)
$$

ここで，$\mathrm{round}$ は最も近い整数への丸めを表し，$\hat{x}$ は $x$ に最も近い代表値である。
もとの振幅値 $x$ と量子化後の振幅値 $\hat{x}$ の差 $e = \hat{x} - x$ を **量子化誤差 (quantization error)** という。
$x$ が範囲 $[x_{\min}, x_{\max}]$ に含まれるとき，量子化誤差の絶対値は $\Delta/2$ 以下である。
量子化誤差が $-\Delta/2$ から $\Delta/2$ の範囲に一様に分布するとみなせる場合，その二乗平均は $\Delta^2/12$ になる。
ビット深度を 1 増やすと，$L$ は 2 倍になり，$\Delta$ はほぼ $1/2$ になる。

#### Python での量子化

```python
def quantize(x, n_bits, x_min=-1.0, x_max=1.0):
    """x を [x_min, x_max] の範囲にある 2**n_bits 個の代表値のうち，最も近い値に量子化する。"""
    L = 2 ** n_bits
    step = (x_max - x_min) / (L - 1)
    index = np.clip(np.round((x - x_min) / step), 0, L - 1)
    return index * step + x_min

v = np.array([-1.0, -0.6, 0.0, 0.3, 0.9, 1.5])
print(quantize(v, 2))  # [-1.         -0.33333333  0.33333333  0.33333333  1.          1.        ]

u = np.linspace(-1.6, 1.6, 1001)
u_q = quantize(u, 2)
error = u_q - u
print(round(np.max(np.abs(error[np.abs(u) <= 1])), 4))  # 0.3333
print(round(np.max(np.abs(error)), 4))                  # 0.6
fig, axes = plt.subplots(2, 1, sharex=True)
axes[0].plot(u, u, label="input")
axes[0].plot(u, u_q, label="2-bit quantized")
axes[0].set_ylabel("Value")
axes[0].legend()
axes[1].plot(u, error)
axes[1].set_ylabel("Quantization error")
axes[1].set_xlabel("Input value")
for ax in axes:
    ax.grid(True)
fig.savefig(figure_dir / "session07_example_quantization.png")
plt.show()
plt.close(fig)
```

`quantize` は，上の式の $\hat{x}$ を配列の各要素について計算する関数である。
`n_bits = 2` のとき，代表値は $-1, -1/3, 1/3, 1$ の 4 個であり，量子化間隔は $2/3$ である。
`np.round` は最も近い整数に丸めるが，ちょうど中間の値（0.5 など）は偶数の側に丸める。
上の例の 0.0 は $(0 + 1)/(2/3) = 1.5$ となって 2 に丸められ，$1/3$ に量子化される。
$L$ が偶数のとき，$-1$ から $1$ までを等間隔に分けた代表値には 0 が含まれない。
`np.clip(a, 0, L - 1)` は，`a` の値を 0 以上 $L - 1$ 以下の範囲に収める。
このため，範囲外の入力 1.5 は端の代表値 1 に量子化され，その量子化誤差の絶対値 0.5 は $\Delta/2 = 1/3$ を超える。
`error[np.abs(u) <= 1]` は，比較で得た真偽値の配列（第3回）を使って，範囲内の入力に対する誤差だけを取り出している。
表示した値と図の下段のとおり，量子化誤差の絶対値は $|u| \le 1$ では $\Delta/2$ 以下だが，範囲外では端から離れるほど大きくなり，$|u| = 1.6$ では 0.6 になる。
返り値は代表値そのものを並べた浮動小数点数の配列であり，代表値の番号（整数）ではない。
第12回では，この `quantize` を，0 から 255 までの範囲の画像の画素値の量子化に使う。

    2. `exercise/exc07_08.py` で，$F_s = 1000$ Hz で 2 秒間標本化した $S_1$，$S_2$，$S_3$，$S_{20}$（それぞれ $x_1$，$x_1 + x_3$，$x_1 + x_3 + x_5$，$\sum_{i=1}^{20} x_{2i-1}$）を作ってください。`plt.subplots(4, 1, sharex=True, figsize=(8, 8))` の各 subplot に 1 つずつ描き，方形波 $s(t)$ を重ねて，`outputs/exc07/exc07_08.png` に保存してください。
    3. $K = 1, 2, 3, 20, 100$ のそれぞれについて，$S_K$ の最大値と，方形波との平均二乗誤差 $\frac{1}{N}\sum_{n=0}^{N-1} (S_K[n] - s[n])^2$ を計算し，$K$，最大値，平均二乗誤差を 1 行ずつ表示してください。この計算では，$S_K$ の最大値の付近にある幅の狭い山を捉えるため，$F_s = 100000$ Hz で 1 秒間標本化してください。
    4. $K$ を大きくすると平均二乗誤差は小さくなるのに，最大値は 1 に近づかないことを確認してください。最大値が 1 を超える部分が $K$ とともにどう変化するかを 2 の図で観察し，平均二乗誤差だけが小さくなる理由を説明してください。この現象は Gibbs 現象と呼ばれます。
    5. $F_s = 1000$ Hz で 2 秒間標本化した $S_{100}$ の最大値も表示し，3 の値より小さくなる理由を，最大値の付近の山の幅とサンプリング周期を比べて説明してください。

2. ビット深度と量子化誤差の関係を調べ，必要なビット深度を見積もります。$x(t) = \sin(2\pi \cdot 5t)$ を $F_s = 1000$ Hz で 1 秒間標本化し，解説の `quantize` 関数（`x_min=-1.0`，`x_max=1.0`）で量子化します。量子化誤差 $e[n] = \hat{x}[n] - x[n]$ の二乗平均（mean squared error, MSE）を，次の式で計算します。

    $$
    \mathrm{MSE} = \frac{1}{N} \sum_{n=0}^{N-1} (e[n])^2
    $$

    1. ビット深度 $B = 2, 4, 8, 16$ のそれぞれについて，量子化間隔 $\Delta$ と，解説の近似値 $\Delta^2/12$ を手計算してください（有効数字 3 桁）。また，$B$ を 1 増やすと MSE がおよそ何倍になるかを予想してください。
    2. `exercise/exc07_09.py` で，$B = 1, 2, \ldots, 16$ のそれぞれについて MSE を計算し，$B$，MSE，$\Delta^2/12$，MSE と $\Delta^2/12$ の比を 1 行ずつ表示してください。$B = 2, 4, 8, 16$ の値を，1 の手計算と比較してください。
    3. 横軸をビット深度，縦軸を MSE とした片対数グラフ（`ax.semilogy`）に，MSE と $\Delta^2/12$ を重ねて描き，`outputs/exc07/exc07_09.png` に保存してください。
    4. 隣り合う $B$ での MSE の比を計算し，1 の予想と比較してください。$B = 1, 2$ で MSE が $\Delta^2/12$ から大きく外れる理由を，量子化誤差が一様に分布するとみなせるかという観点から説明してください。また，$B$ が大きくても比が 1 から 10% 以上ずれることがある理由を，この信号に含まれる異なる値の個数から考察してください。異なる値の個数は，丸め誤差による違いを除くため `np.unique(np.round(x, 10)).size` で数えてください。
    5. MSE を $10^{-8}$ 以下にしたいとします。$\Delta^2/12 \le 10^{-8}$ を満たす最小のビット深度を手計算で見積もり，2 の結果で実際に $\mathrm{MSE} \le 10^{-8}$ を満たす最小のビット深度と比較してください。2 つが一致しない場合は，その理由を説明してください。

3. サンプリング定理の復元式を使って，標本化した信号から連続時間信号を復元します。$x(t) = \cos(2\pi \cdot 3t) + 0.5\sin(2\pi \cdot 7t)$ を $F_s = 20$ Hz で 4 秒間標本化した $x_{20}[n]$ と，それを間引いた $x_{10}[n] = x_{20}[2n]$ を使います。復元した信号は，$0 \le t < 4$ を 1 ms 間隔で並べた 4000 点の時刻で計算し，元の $x(t)$ と比べます。

    1. $x(t)$ に含まれる最も高い周波数を答えてください。$F_s = 20$ Hz と，間引いた後のサンプリング周波数 10 Hz のそれぞれが，サンプリング定理の条件を満たすかを判断してください。条件を満たさない場合は，解説のエイリアシングの式を使って，$0.5\sin(2\pi\cdot 7t)$ のサンプルが何 Hz のどのような正弦波のサンプルと一致するかを手計算してください。$\sin\theta = \cos(\theta - \pi/2)$ を使えます。
    2. `exercise/exc07_10.py` で $x_{20}[n]$ を作り，`x20[::2]` で $x_{10}[n]$ を作ってください。$x_{10}[n]$ が，$x(t)$ を $F_s = 10$ Hz で直接 4 秒間標本化した信号と一致することを，`np.allclose` で確かめてください。
    3. 解説の復元式の和を，手元にあるサンプル（$n = 0, 1, \ldots, N-1$）だけで打ち切って計算する関数 `reconstruct(x_s, Fs, t)` を定義してください。`t[:, np.newaxis] - n / Fs` のようにブロードキャスト（第3回）で形 `(len(t), N)` の配列を作ってから `np.sinc` に渡すと，`for` 文を使わずに計算できます。
    4. $x_{20}$ と $x_{10}$ から復元した信号のそれぞれについて，元の $x(t)$ との差の絶対値の最大値を，$0 \le t < 4$ 全体と，中央の $1 \le t \le 3$ の範囲で表示してください。`plt.subplots(2, 1, sharex=True)` の上段に $F_s = 20$ Hz，下段に $F_s = 10$ Hz の結果（元の信号，復元した信号，サンプルの `stem`）を描き，`outputs/exc07/exc07_10.png` に保存してください。
    5. $F_s = 10$ Hz で復元した信号と，1 で求めた正弦波で $0.5\sin(2\pi\cdot 7t)$ を置き換えた信号との差の絶対値の最大値を，中央の範囲で表示してください。この結果を使って，$F_s = 10$ Hz のサンプルから元の信号を復元できない理由を説明してください。また，$F_s = 20$ Hz でも両端付近で誤差が大きくなる理由を，和の打ち切りから説明してください。
