# 第02回 Python 基礎

## この回の目標

- 変数に値を入れ，型と値を確認する。
- 関数，条件分岐，繰り返しを組み合わせて小さな処理を書く。
- list，dict，スライスを使って複数の値を扱う。
- 実行結果をコードコメントや結果ファイルに残し，後から確認できる状態にする。

## 解説
- 変数は値に名前を付ける仕組みである。型を確認すると，数値，文字列，list，dict のどれとして処理されているかを切り分けやすい。
- 関数は処理に名前を付け，再利用しやすくするために使う。入力，引数，返り値を意識すると，処理の境界が明確になる。
- 条件分岐は場合分け，繰り返しは同じ処理の反復に使う。両者を list や dict と組み合わせると，データの変換や集計を簡潔に書ける。
- スライスは連続した範囲を取り出す表記である。開始，終了，刻み幅の意味を確認すると，NumPy 配列や信号処理の切り出しにもつながる。

### 基礎レベル
1. **値・型・例外を区別する。** `1.2 + 3.8`，`10 // 100`，`1 >= 0`，`abs(-3)` の値と型を予想してから確認する。`2 // 0` は意図的な失敗例として別に実行し，例外名を記録する。例外で後の確認が中断しないようにする。
2. **スライスを予測する。** `a = [4, 8, 3, 4, 1]` について，`len(a)`，`sum(a)`，`a[1:4]`，`a[::2]`，`a[::-1]` を実行前に予想する。終了位置を含まないことと負の刻みの意味を説明する。`a + [100]` の結果と元の `a` も確認する。
3. **forとifを追跡する。** 下のコードで，各反復後の `x` と `total` を表にしてから実行する。`if` を `x % 2 != 0` へ変えると何が変わるかも予想する。

   ```python
   a = [4, 8, 3, 4, 1]
   total = 0
   for x in a:
       if x % 2 == 0:
           total += x
   print(total)
   ```

4. **関数の返り値と辞書を使う。** `is_passed(score)` が70点以上で `True`，未満で `False` を返すように実装する。69，70，71で境界を確認する。`scores = {"alice": 82, "bob": 61, "carol": 95, "dave": 58}` から合格者名のリストを作る。関数内の `return` を `print` に置き換えた場合，呼び出し側で受け取る値がどうなるか説明する。

2. `a = [1, 2, 3]` を関数へ渡し，関数内で `a = [6, 7, 8]` とする場合と `a.append(1)` とする場合で，呼び出し後のリストを比較する。代入と変更の違いを説明する。

## 確認ポイント
- 値・型・例外を区別し，意図的な例外を通常の成功結果と混同していない。
- スライスの予測，for/ifの追跡表，関数の境界値確認がある。
- コードを作業repoのルートから再実行でき，コードコメントまたは既存の結果ファイルに予想との差と理由がある。
- 発展課題は選択した項目だけを確認する。
