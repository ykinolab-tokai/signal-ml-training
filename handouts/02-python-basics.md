## 解説

### 1. 変数と型

#### 代入と値の確認

**変数 (variable)** は，値に名前を付けて，後から参照できるようにする仕組みである。
`名前 = 式` と書くと，右辺を計算した結果が左辺の名前に対応付けられる。この操作を **代入 (assignment)** という。
Python のプログラムは基本的に上から順に実行され，`print()` を使うと値を表示できる。

```python
x = 3
y = x + 2
x = 10
print(x, y)  # => 10 5
```

`y` に代入されるのは，その時点での `x + 2` の計算結果である。
後から `x` を変更しても，`y` の値は更新されない。
コード中の `#` から行末までは **コメント** であり，実行されない。
以下の例では，`# =>` の後に表示結果を示す。

#### 基本的な型

値の種類を **型 (type)** と呼ぶ。型によって，可能な演算や処理の意味が異なる。

| 型 | 意味 | 値の例 |
| --- | --- | --- |
| `int` | 整数 | `3`, `-2` |
| `float` | 浮動小数点数 | `0.5`, `-1.2` |
| `bool` | 真偽値 | `True`, `False` |
| `str` | 文字列 | `"hello"`, `'Python'` |
| `list` | 順序を持つ要素の並び（リスト） | `[2, 5, 8]` |
| `dict` | キーと値の対応（辞書） | `{"name": "alice", "score": 82}` |

`type()` で型を確認できる。例えば，数値の `3` と文字列の `"3"` は異なる型の値である。

```python
print(type(3))          # => <class 'int'>
print(type("3"))        # => <class 'str'>
print(3 + 2)           # => 5
print("3" + "2")       # => 32
print(int("3") + 2)    # => 5
```

文字列どうしの `+` は連結を表す。`int("3")` は文字列を整数に変換する。
数値と文字列をそのまま `+` で足すと，
演算対象（オペランド）の型の組み合わせが不適切であることを示す `TypeError` が発生する。

#### 演算と比較

数値には，四則演算 `+`, `-`, `*`, `/` のほか，次の演算を使える。

| 式 | 意味 | 結果 |
| --- | --- | --- |
| `7 / 2` | 除算 | `3.5` |
| `7 // 2` | 商を負の無限大方向に丸める除算 | `3` |
| `-7 // 2` | 負の値に対する同じ除算 | `-4` |
| `7 % 2` | 剰余 | `1` |
| `2 ** 3` | べき乗 | `8` |

また，値を比較する `==`, `!=`, `<`, `<=`, `>`, `>=` は，`True` または `False` を返す。
`=` は代入，`==` は等しいかどうかの比較であり，異なる演算を表すため注意が必要である。
真偽値の条件を組み合わせるには，`and`（両方が真），`or`（少なくとも一方が真），`not`（真偽の反転）を使う。
例えば，`0 <= x and x <= 100` は「`x` が 0 以上かつ 100 以下」を表す。

ゼロで割ると `ZeroDivisionError` が発生する。
エラーが発生すると，処理を続けるための記述がない限り，そこで実行が停止する。
エラーになる式を実行する演習では，他の式と分けて実行するか都度結果を表示する必要がある。

### 2. リストとスライス

#### 要素の参照と更新

**リスト (list)** は，複数の値を順序付きでまとめるデータ構造である。
各値を **要素**，要素の位置を表す整数を **インデックス (index)** と呼ぶ。
インデックスは `0` から始まり，負のインデックスは末尾からの位置を表す。

```python
values = [10, 20, 30, 40, 50]
print(values[0])   # => 10
print(values[-1])  # => 50
values[1] = 25
values.append(60)
print(values)     # => [10, 25, 30, 40, 50, 60]
```

`values[1] = 25` はインデックス `1` に対応する要素の更新，`values.append(60)` は末尾への要素 `60` の追加である。
`append()` のように，`対象.名前(...)` の形で呼び出す，その対象に属する処理を **メソッド (method)** という。
`del values[0]` で先頭の要素を削除でき，`values.pop()` で末尾の要素を取り除いてその値を受け取ることができる。
存在しない位置の要素を `values[インデックス]` で参照すると `IndexError` が発生する。

#### スライスによる範囲の取り出し

**スライス (slice)** は，`リスト[開始:終了:刻み幅]` の形で複数の要素を取り出す表記である。
開始位置の要素は含むが，終了位置の要素は含まない。

```python
values = [10, 20, 30, 40, 50]
print(values[1:4])   # => [20, 30, 40]
print(values[:3])    # => [10, 20, 30]
print(values[3:])    # => [40, 50]
print(values[::2])   # => [10, 30, 50]
print(values[::-1])  # => [50, 40, 30, 20, 10]
```

刻み幅を省略すると `1` になる。正の刻み幅では，開始を省略すると先頭から，終了を省略すると末尾まで取り出す。
負の刻み幅は末尾から先頭へ要素を取り出すことを表し，`[::-1]` はリストの要素を逆順に取り出す。
リストのスライスは新しいリストを作るため，これらの式を実行しても元のリストは変化しない。

#### 組み込み関数

Python があらかじめ用意していて，追加の読み込みなしで使える関数を **組み込み関数 (built-in function)** という。
例えば，`len(values)` は要素数を返す。
リスト全体の集計や並べ替えにも組み込み関数が用意されており，それらは公式ドキュメントから確認できる。
関数やメソッドを使うときは，「何を返すか」と「元のデータを変更するか」の両方を確認する。
例えば，`append()` はリストを変更するが，変更後のリストを返すわけではない。

### 3. 条件分岐と繰り返し

#### if 文とインデント

条件に応じて実行する処理を変えることを **条件分岐** という。
`if` に続く条件が真ならその直下の処理を実行し，偽なら `elif` の条件を順に調べる。
どの条件も満たさなければ `else` の処理を実行する。
`elif` と `else` は省略できるため，必要な場合だけ書く。

```python
value = -2
if value > 0:
    print("positive")
elif value == 0:
    print("zero")
else:
    print("negative")  # => negative
```

条件の行の末尾には `:` を付け，その条件で実行する行は **インデント（字下げ）** する。
Python ではインデントが処理のまとまり（ブロック）を決めるため，同じまとまりの行は深さをそろえる。
この資料では，1段階のインデントに半角スペース4個を使う。

#### for 文による反復と集計

**繰り返し（反復）** は，同じ処理を複数回実行するために使う。
`for 変数 in 対象:` と書くと，対象から要素を1つずつ取り出して変数に代入し，直後のインデントされたブロックを実行する。
リストや文字列のように，要素を順に取り出せる対象を **イテラブル (iterable)** という。

```python
values = [2, 5, 8]
total = 0
for value in values:
    total = total + value
print(total)  # => 15
```

この例では，`total` が `0 → 2 → 7 → 15` と変化する。
集計用の変数はループの前で初期化する。ループの内側で `total = 0` とすると，それまでの合計が毎回失われる。
`total = total + value` は `total += value` とも書ける。

整数を順に取り出すには `range(開始, 終了, 刻み幅)` を使う。
`range(4)` は `0, 1, 2, 3`，`range(2, 5)` は `2, 3, 4` を順に生成する。
スライスと同様に終了の値は含まず，刻み幅の省略時は `1` となる。
ループの途中で `break` を実行するとループを終了し，`continue` を実行するとその回の残りの処理を飛ばして次の反復へ進む。

#### リスト内包表記

各要素を変換して新しいリストを作る処理は，**リスト内包表記 (list comprehension)** で簡潔に書ける。
次の2つの書き方は，同じリストを作る。

```python
values = [2, 5, 8]
doubled = []
for value in values:
    doubled.append(2 * value)
print(doubled)  # => [4, 10, 16]

doubled = [2 * value for value in values]
print(doubled)  # => [4, 10, 16]
```

`[式 for 変数 in 対象 if 条件]` と末尾に条件を付けると，条件を満たす要素だけを使う。
例えば，`[2 * value for value in values if value > 4]` は `[10, 16]` となる。
「各要素をどう変換するか」を表す式と，「どの要素を使うか」を表す条件を区別する。

### 4. 辞書

**辞書 (dictionary, dict)** は，**キー (key)** と **値 (value)** を対応付けるデータ構造である。
リストでは位置で要素を指定するのに対し，辞書ではキーで値を指定する。
例えば，測定場所の名前をキー，その場所の温度を値として記録できる。

```python
temperatures = {"room_a": 22.5, "room_b": 24.0}
print(temperatures["room_a"])  # => 22.5
temperatures["room_a"] = 23.0
temperatures["room_c"] = 21.5
for name, temperature in temperatures.items():
    print(name, temperature)
```

既存のキーへの代入は値の更新，新しいキーへの代入は項目の追加になる。
`items()` を使うと，キーと値を組にして取り出せる。
上のループでは，それぞれを `name` と `temperature` に代入し，`room_a 23.0`，`room_b 24.0`，`room_c 21.5` を1行ずつ表示する。
`for name in temperatures:` と書いた場合は，キーだけを取り出す。

存在しないキーを `辞書[キー]` で参照すると `KeyError` が発生する。
`キー in 辞書` で存在を確認でき，`辞書.get(キー, 初期値)` ではキーがないときに指定した初期値を受け取れる。
例えば，単語 `word` の出現回数を数える処理では `counts[word] = counts.get(word, 0) + 1` と書くことができる。
辞書の値としてリストや別の辞書を使えば，複数の測定値や，点数と合否のような関連する情報をまとめられる。

### 5. 関数

#### 定義，引数，返り値

**関数 (function)** は，一連の処理に名前を付けて再利用する仕組みである。
`def 関数名(引数):` で定義し，インデントした部分に処理を書く。
関数に渡す入力を **引数 (argument)**，`return` で呼び出し元へ返す結果を **返り値 (return value)** という。

```python
def scale(value, factor):
    result = value * factor
    return result

scaled = scale(3, 2)
print(scaled)  # => 6
```

定義しただけでは関数の中身は実行されない。`scale(3, 2)` と呼び出したときに，`value` に `3`，`factor` に `2` が渡される。
関数内で代入した `result` は，その関数の中で使う **ローカル変数** である。
`return` を実行すると関数は終了し，この例では返された `6` が `scaled` に代入される。

`print()` は画面への表示，`return` は計算結果の受け渡しであり，用途が異なる。
返り値を指定せずに終了した関数は，「値がない」ことを表す `None` を返す。
条件判定を関数にする場合は，比較式の結果である `True` または `False` を返すと，呼び出し側の `if` 文で使える。

#### 再代入とデータの変更

Python が扱う数値やリストなどの実体を **オブジェクト (object)** と呼ぶ。
変数はオブジェクトを参照する名前であり，変数を別の変数に代入する操作は，元の変数が指し示すオブジェクトに別名をつけることに相当する。

```python
original = [10, 20]
other = original
other.append(30)
print(original)  # => [10, 20, 30]

other = [0]
print(original)  # => [10, 20, 30]
print(other)     # => [0]
```

`other = original` の直後は，2つの名前が同じリストを参照する。
そのため， `other` が指すリストに変更を加えると， `original` から見てもその変更が反映される。
一方，`other = [0]` は，新たなリスト `[0]` を作成してそれに `other` という名前をつける操作であり，
`original` が指すリストの内容を変化させたり， `original` が指す対象を変更したりする操作ではない。

リストや辞書のように内容を変更できるものを **ミュータブル (mutable)**，数値や文字列のように内容を変更できないものを **イミュータブル (immutable)** という。

### 6. 文字列の操作

**文字列 (str)** は，文字の並びを表す型であり，引用符 `'...'` または `"..."` で囲んで記述する。
リストと同様に，インデックスやスライスで文字を取り出せる。ただし，文字列の一部を直接書き換えることはできない。

```python
text = "Python"
print(text[0])   # => P
print(text[:3])  # => Pyt
```

複数の文字列を区切り文字でつなぐには，`区切り文字.join(文字列の並び)` を使う。
数値を文字列に変換するには，`str()` を用いる。

```python
labels = [str(value) for value in [2, 5, 8]]
print(", ".join(labels))       # => 2, 5, 8
print("{:.2f}".format(1 / 3))  # => 0.33
```

`format()` は，文字列中の `{}` に値を埋め込むメソッドである。
`{:.2f}` は小数点以下2桁の固定小数点表記を指定し，表示する値を丸める。

### 7. クラスとインスタンス

**クラス (class)** は，データと，そのデータに対する操作をまとめて定義する仕組みである。
クラスから作られた個々のオブジェクトを **インスタンス (instance)**，インスタンスが持つデータを **属性 (attribute)** と呼ぶ。
例えば，次の `Counter` クラスは，数えた回数を属性 `value` に保持し，メソッド `add()` で更新する。

```python
class Counter:
    def __init__(self, initial):
        self.value = initial

    def add(self, amount):
        self.value += amount

    def current(self):
        return self.value

counter = Counter(2)
another = Counter(10)
counter.add(3)
print(counter.current())  # => 5
print(another.current())  # => 10
```

- `class Counter:`：クラスを定義する。
- `Counter(2)`：インスタンスを作る。初期化の際に `__init__()` が呼ばれ，`initial` に `2` が渡される。
- `self`：そのメソッドを呼び出したインスタンス自身を表す。`counter.add(3)` では，`self` に `counter`，`amount` に `3` が渡される。
- `self.value`：インスタンスの属性を参照する。メソッドを呼び終わった後も，値をインスタンスに保持できる。

この例では，各インスタンスがそれぞれの `value` を持つため，`counter` を更新しても `another` の値は変わらない。
リストの `append()` も，リストというオブジェクトに対するメソッドの呼び出しである。

7. NumPy Array，PyTorch Tensor，`nn.Module` などを理解するには，Python のクラスに慣れておく必要があります。クラスを実装する練習として，データを管理するクラスを実装してください。次のメソッドをすべて持つクラス `DataManager` を `exercise/exc02_07.py` に書いてください。

    - `__init__(self, x, y, z)`: 3つの数 `x`，`y`，`z` を受け取り，インスタンスの属性としてそれぞれの値を記憶します。
    - `add_x(self, delta)`: `x` に `delta` だけ足して，値を更新します。
    - `add_y(self, delta)`: `y` に `delta` だけ足して，値を更新します。
    - `add_z(self, delta)`: `z` に `delta` だけ足して，値を更新します。
    - `sum(self)`: `x`，`y`，`z` の3つの数の合計値を返します。

    このクラスを使って，以下のようなコードが書けるものとします。

    ```python
    data_manager = DataManager(2, 3, 5)
    print(data_manager.sum())  # => 10
    data_manager.add_x(4)      # => data_manager.x の値が 2 から 6 に更新されます
    print(data_manager.sum())  # => 14
    data_manager.add_y(0)      # => data_manager.y の値が 3 から 3 に更新されます
    print(data_manager.sum())  # => 14
    data_manager.add_z(-9)     # => data_manager.z の値が 5 から -4 に更新されます
    print(data_manager.sum())  # => 5
    ```
