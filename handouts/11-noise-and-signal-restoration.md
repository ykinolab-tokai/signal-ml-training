### 1. 加法性ノイズのモデル

#### 観測信号と加法性ノイズ

測定や通信で得られる信号には，目的の信号のほかに，目的と関係のない変動が加わる。
この変動を **ノイズ (noise)** という。
最も単純なモデルでは，観測した信号 $y[n]$ を，元の信号 $s[n]$ とノイズ $v[n]$ の和として表す。

$$
y[n] = s[n] + v[n]
$$

このように信号に足し合わされるノイズを **加法性ノイズ (additive noise)** という。
以下では，ノイズを含まない $s$ を **クリーン信号 (clean signal)**，$y$ を **観測信号 (observed signal)** と呼ぶ。
観測信号 $y$ から $s$ を推定することを **信号復元 (signal restoration)** といい，推定した信号を $\hat{s}$ と書く。
実際の観測では $s$ は分からない。
一方，自分で作ったクリーン信号に自分で作ったノイズを加える **合成実験 (synthetic experiment)** では，$\hat{s}$ と $s$ を直接比べて，復元方法を評価できる。

#### 正規分布に従うノイズ

この回では，各時刻のノイズ $v[n]$ が，平均 0，標準偏差 $\sigma$ の正規分布（第6回）に，時刻ごとに独立に従うとする。
信号の値の 2 乗の平均 $\frac{1}{N}\sum_{n=0}^{N-1}x[n]^2$ を，信号の **平均パワー (average power)** という（教科書の第13章では平均電力と呼んでいる）。
このノイズの平均パワーは，標本数 $N$ が大きければ，分散 $\sigma^2$ に近い値になる。
振幅 $A$ の正弦波の平均パワーは，整数個の周期にわたって平均すると $A^2/2$ である。
周波数の異なる 2 つの正弦波の和では，どちらの正弦波も整数個の周期を含む区間で平均すると，2 つの積の平均が 0 になるので，平均パワーはそれぞれの平均パワーの和になる。

```python
fs = 400                                     # サンプリング周波数 [Hz]
t = np.arange(fs) / fs                       # 1 秒分の時刻
clean = 0.8 * np.sin(2 * np.pi * 3 * t) + 0.4 * np.sin(2 * np.pi * 30 * t)
sigma = 0.3
rng = np.random.default_rng(9)
noise = rng.normal(0.0, sigma, size=t.size)
noisy = clean + noise
print(t.shape, noisy.shape)  # (400,) (400,)
print(np.mean(clean**2))  # 約 0.4
print(round(noise.mean(), 4), round(noise.std(), 4))  # 0.0057 0.299

fig, axes = plt.subplots(3, 1, sharex=True)
for ax, x, label in zip(axes, [clean, noise, noisy], ["clean", "noise", "noisy"]):
    ax.plot(t, x)
    ax.set_ylabel(label)
axes[-1].set_xlabel("time [s]")
fig.tight_layout()
fig.savefig(figure_dir / "session11_example_noisy.png")
plt.show()
plt.close(fig)
```

`clean` は，振幅 0.8 の 3 Hz の正弦波と振幅 0.4 の 30 Hz の正弦波の和であり，平均パワーは $0.8^2/2+0.4^2/2=0.4$ である。
`rng.normal(0.0, sigma, size=t.size)` は，平均 0，標準偏差 `sigma` の正規分布に従う乱数を `t` と同じ個数だけ作る（第6回）。
`scale` に当たる第 2 引数は分散ではなく標準偏差である。
標本から計算した平均と標準偏差は，0 と $\sigma=0.3$ に近いが，一致はしない。
seed を固定しないと実行のたびにノイズが変わり，復元方法の比較が再現できなくなるため，合成実験では seed を固定する。

### 2. 誤差と SNR

#### 平均二乗誤差と最大絶対誤差

復元の良さは，推定 $\hat{s}$ とクリーン信号 $s$ の差 $\hat{s}-s$ で評価する。
差の 2 乗の平均を **平均二乗誤差 (mean squared error, MSE)** という。

$$
\mathrm{MSE} = \frac{1}{N}\sum_{n=0}^{N-1}\bigl(\hat{s}[n]-s[n]\bigr)^2
$$

何も処理せずに $\hat{s}=y$ とすると，$\hat{s}-s=v$ なので，MSE はノイズの平均パワーに等しい。
MSE は誤差を平均した量なので，一部の時刻だけで誤差が大きくなっても，値にはあまり表れない。
誤差の最悪の値を調べるには，**最大絶対誤差 (maximum absolute error)** $\max_n|\hat{s}[n]-s[n]|$ を使う。

#### SNR

信号の大きさに対する誤差の大きさを表す量として，**SN 比 (signal-to-noise ratio, SNR)** を使う。

$$
\mathrm{SNR} = 10\log_{10}\frac{\sum_{n} s[n]^2}{\sum_{n} \bigl(\hat{s}[n]-s[n]\bigr)^2}\ \ [\mathrm{dB}]
$$

SNR は，クリーン信号のパワーと誤差のパワーの比を，第9回で扱ったデシベルで表した値である。
パワーの比なので $10\log_{10}$ を使い，振幅の比に使う $20\log_{10}$ とは区別する。
パワーの比が 10 倍なら 10 dB，100 倍なら 20 dB であり，SNR が大きいほど誤差が小さい。
MSE は小さいほど良く，SNR は大きいほど良いことに注意する。
$\hat{s}=y$ としたときの SNR を **入力 SNR (input SNR)**，復元後の SNR を **出力 SNR (output SNR)** と呼び，その差を SNR の改善量として比べることがある。

```python
error = noisy - clean
print(round(np.mean(error**2), 4))  # 0.0895
print(round(10 * np.log10(np.sum(clean**2) / np.sum(error**2)), 2))  # 6.5
print(round(10 * np.log10(np.mean(clean**2) / sigma**2), 2))  # 6.48
print(round(np.max(np.abs(error)), 4))  # 0.8824
```

1 行目の MSE は，ノイズの平均パワーであり，$\sigma^2=0.09$ に近い。
2 行目は観測信号の SNR（入力 SNR）である。
3 行目は，クリーン信号の平均パワー 0.4 とノイズの分散 $\sigma^2$ から計算した SNR の値 $10\log_{10}(0.4/0.09)$ である。
2 つの値の違いは，標本から計算したノイズの平均パワーが $\sigma^2$ と一致しないことによる。
`np.sum(clean**2) / np.sum(error**2)` の分子と分母を入れ替えると SNR の符号が反転するので，引数の順序に注意する。

### 3. ノイズのスペクトル

#### パワースペクトル

長さ $N$ の信号 $x[n]$ の DFT を $X[k]$ とするとき，$P[k]=|X[k]|^2/N$ を **パワースペクトル (power spectrum)** と呼ぶ。
DFT について，**Parseval の定理 (Parseval's theorem)** $\sum_{n}|x[n]|^2=\frac{1}{N}\sum_{k}|X[k]|^2$ が成り立つ。
このため，$P[k]$ を $k=0,\ldots,N-1$ のすべてについて平均すると，信号の平均パワー $\frac{1}{N}\sum_n|x[n]|^2$ に等しくなる。
つまり，$P[k]$ は，平均パワーが各周波数にどのように分かれているかを表す。
第9回で見たように，振幅 $A$ の正弦波の周波数が周波数ビン $k_0$ にちょうど一致するとき，$|X[k_0]|=AN/2$ なので，$P[k_0]=A^2N/4$ である。

#### 白色ノイズ

各時刻の値が平均 0，分散 $\sigma^2$ で互いに独立なノイズでは，パワースペクトルの期待値がすべての $k$ で $\sigma^2$ になる。
このように，すべての周波数に同じ強さで広がっているノイズを **白色ノイズ (white noise)** という。
白色光がさまざまな色（周波数）の光を含むことにちなんだ名前である。
ただし，1 回の実験で得たノイズの $P[k]$ は，期待値 $\sigma^2$ のまわりで大きくばらつく。
このため，パワースペクトルが平らかどうかは，1 つの $k$ の値ではなく，多くの $k$ についての平均や図全体の傾向で判断する。

```python
N = t.size
f = np.fft.rfftfreq(N, d=1 / fs)             # 0, 1, ..., 200 Hz
P_clean = np.abs(np.fft.rfft(clean))**2 / N
P_noise = np.abs(np.fft.rfft(noise))**2 / N
P_noisy = np.abs(np.fft.rfft(noisy))**2 / N
print(f.shape, f[1])  # (201,) 1.0
print(P_clean[[3, 30]])  # [64. 16.]
print(round(P_noise.mean(), 4), round(P_noise.max(), 4))  # 0.0897 0.5225
print(round(np.mean(P_noise > sigma**2), 3))  # 0.373
print(round(np.mean(np.abs(np.fft.fft(noise))**2) / N, 4), round(np.mean(noise**2), 4))  # 0.0895 0.0895

fig, ax = plt.subplots()
ax.semilogy(f, P_noisy, label="noisy")
ax.semilogy(f, P_noise, label="noise")
ax.axhline(sigma**2, color="black", linestyle="--", label="sigma**2")
ax.set_ylim(1e-4, 1e3)
ax.set_xlabel("frequency [Hz]")
ax.set_ylabel("power")
ax.legend()
fig.savefig(figure_dir / "session11_example_power_spectrum.png")
plt.show()
plt.close(fig)
```

`np.fft.rfft` と `np.fft.rfftfreq` は第9回と同じ使い方であり，この例では周波数ビンの間隔が $F_s/N=1$ Hz なので，$k$ 番目の要素が $k$ Hz に対応する。
クリーン信号のパワースペクトルは，3 Hz と 30 Hz で $0.8^2\times400/4=64$ と $0.4^2\times400/4=16$ になり，それ以外の周波数ではほぼ 0 である。
ノイズのパワースペクトルの平均は約 0.09 で $\sigma^2$ に近いが，最大値は約 0.52 であり，約 37% の周波数ビンで $\sigma^2$ を超えている。
最後の行は，`np.fft.fft` で計算したすべての $k$ についての $P[k]$ の平均が，平均パワーと一致することを確かめている。
`np.fft.rfft` が返す $0\le k\le N/2$ の範囲だけで平均すると，この関係は近似的にしか成り立たない。
パワースペクトルは値の範囲が広いので，`ax.semilogy` で縦軸を対数にして描くとよい。
図では，観測信号のパワースペクトルが 3 Hz と 30 Hz でノイズより大きく突き出し，それ以外ではノイズとほぼ同じになる。

### 4. 移動平均フィルタ

#### LTI システムとしての移動平均

連続する $M$ 個のサンプルの平均を出力するシステムを **移動平均フィルタ (moving-average filter)** といい，平均をとるサンプル数 $M$ を移動平均の窓長と呼ぶ。
移動平均フィルタは，インパルス応答が $h[n]=1/M$（$n=0,\ldots,M-1$）の FIR システムであり，出力は畳み込み $y*h$ で計算できる（第10回）。
周波数応答は，第10回の第5節の $H(e^{j\omega})=\sum_n h[n]e^{-j\omega n}$ に等比数列の和の公式を使うと，次の大きさを持つ。

$$
|H(e^{j\omega})| = \left|\frac{\sin(M\omega/2)}{M\sin(\omega/2)}\right|
$$

$|H|$ は $\omega=0$ で 1 となり，$\omega=2\pi m/M$（$m=1,2,\ldots$）で 0 になる。
周波数 $F$ [Hz] では $\omega = 2\pi F/F_s$ なので，$F = mF_s/M$ で 0 になる。
したがって，移動平均フィルタは低域通過フィルタであり，$M$ を大きくするほど，通過させる周波数の範囲が狭くなる。

#### 白色ノイズに対する効果

インパルス応答 $h$ の LTI システムに白色ノイズを入力すると，出力の各値は独立な値の重み付き和になるため，出力の分散は $\sigma^2\sum_n h[n]^2$ になる。
移動平均フィルタでは $\sum_n h[n]^2=M\times(1/M)^2=1/M$ なので，出力に残るノイズの分散は $\sigma^2/M$ である。
一方，クリーン信号の成分も，その周波数での $|H|$ 倍に弱められる。
移動平均フィルタは線形なので，観測信号に対する出力は，クリーン信号に対する出力とノイズに対する出力の和になる。
したがって，誤差は，クリーン信号が変形したことによる誤差と，残ったノイズの和に分けて考えられる。
ノイズを減らすために $M$ を大きくすると，信号の速い変化まで失われる。

#### 中央をそろえた計算と端の扱い

`np.convolve(y, h, mode="same")` は，`mode="full"` の結果から中央の $N$ 個を取り出す（第10回）。
$M$ が奇数のとき，これは各時刻の前後 $(M-1)/2$ 個ずつを含む $M$ 個の平均であり，出力は入力に対して遅れない。
`mode="full"` の結果の先頭 $N$ 個を使うと，出力は $(M-1)/2$ サンプル遅れる。
配列の両端では，範囲の外の値を 0 として平均するため，出力が 0 に近づく。

```python
M = 5
h = np.ones(M) / M
H = np.fft.rfft(h, n=N)                      # 1 Hz 刻みの周波数応答
print(np.round(np.abs(H[[0, 3, 30, 80]]), 4))  # [1.     0.9978 0.7915 0.    ]

ma = np.convolve(noisy, h, mode="same")
ma_noise = np.convolve(noise, h, mode="same")
print(ma.shape)  # (400,)
print(round(ma_noise.std(), 4), round(sigma / np.sqrt(M), 4))  # 0.1377 0.1342
print(round(np.mean((ma - clean)**2), 4))  # 0.0227
print(np.convolve(np.ones(6), np.ones(3) / 3, mode="same"))  # [0.66666667 1.         1.         1.         1.         0.66666667]
```

`np.fft.rfft(h, n=N)` は，第10回の第5節と同様に，`h` をゼロ埋めして周波数応答を計算している。
$N=F_s$ なので，添字 0，3，30，80 はそれぞれ 0 Hz，3 Hz，30 Hz，80 Hz に対応する。
$M=5$ では $F_s/M=80$ Hz で $|H|=0$ となり，30 Hz の成分は約 0.79 倍に弱められる。
ノイズだけを通した出力の標準偏差は約 0.138 であり，$\sigma/\sqrt{M}\approx0.134$ に近い。
観測信号の MSE は 0.0895 から 0.0227 に下がっている。
最後の行は，すべて 1 の信号を移動平均すると，両端の値だけが $2/3$ になることを示している。

### 5. 周波数領域でのフィルタ処理

第10回の畳み込み定理より，LTI システムの処理は，DFT に周波数ごとの倍率を掛ける処理として書ける。
逆に，観測信号の DFT $Y[k]$ に，周波数ごとに決めた倍率 $G[k]$ を掛けてから逆 DFT で戻すと，周波数ごとに成分を残したり除いたりできる。

$$
\hat{S}[k] = G[k]\,Y[k],\qquad \hat{s} = \mathrm{IDFT}\bigl(\hat{S}\bigr)
$$

例えば，周波数 $f_c$ [Hz] 以下の周波数ビンで $G[k]=1$，それ以外で $G[k]=0$ とすると，$f_c$ 以下の成分だけが残る。
このフィルタを **理想低域通過フィルタ (ideal low-pass filter)** といい，$f_c$ を **遮断周波数 (cutoff frequency)** という。
実数の信号では，`np.fft.rfft` で計算した $0\le k\le N/2$ の成分に倍率を掛けて `np.fft.irfft` で戻すと，負の周波数の成分（$N/2<k<N$）にも同じ倍率を掛けたことになる。
DFT の積は巡回畳み込みに対応する（第10回）ので，この処理は信号を周期 $N$ で繰り返したものとして扱っており，信号の先頭と末尾がなめらかにつながらない場合は両端の結果に注意する。

```python
Y = np.fft.rfft(noisy)
G = (f <= 50).astype(float)                  # 50 Hz 以下を残す
lowpass = np.fft.irfft(G * Y, n=N)
print(Y.shape, lowpass.shape)  # (201,) (400,)
print(int(G.sum()), round(np.mean((lowpass - clean)**2), 4))  # 51 0.0223
```

`f <= 50` は要素ごとの真偽値の配列であり，`.astype(float)` で 1.0 と 0.0 の配列に変換している。
`np.fft.irfft(..., n=N)` の `n` には，元の信号の長さを指定する。
`n` を省略すると長さ $2(L-1)$（$L$ は入力の長さ）の信号が返るため，$N$ が奇数のときに元の長さと一致しない。
この例では，$0\le k\le 50$ の 51 個の周波数ビンを残している。
負の周波数の側も含めると $N=400$ 個のうち $1+2\times50=101$ 個の成分が残るので，残るノイズのパワーは $\sigma^2\times101/400\approx0.0227$ と見積もられ，MSE 0.0223 とほぼ一致する。
3 Hz と 30 Hz の成分は遮断周波数より低いので，そのまま残る。

### 6. Wiener フィルタ

#### 周波数ごとの最適な倍率

各周波数ビンの倍率 $G$ を，推定の誤差の 2 乗の期待値が最小になるように決めることを考える。
$Y[k]=S[k]+V[k]$ であり，ノイズの DFT $V[k]$ の期待値は 0 である。
$S[k]$ を固定し，ノイズについての期待値を $E[\cdot]$ と書くと，実数の倍率 $G$ に対して次の式が成り立つ。

$$
E\bigl[|G\,Y[k]-S[k]|^2\bigr] = (1-G)^2|S[k]|^2 + G^2\,E\bigl[|V[k]|^2\bigr]
$$

右辺の第 1 項は信号を弱めすぎることによる誤差，第 2 項は残ったノイズによる誤差である。
両辺を $N$ で割り，信号のパワースペクトル $P_s[k]=|S[k]|^2/N$ とノイズのパワースペクトル $P_n[k]=E[|V[k]|^2]/N$ を使って，右辺を $G$ で微分して 0 とおくと，次の倍率が得られる。

$$
H[k] = \frac{P_s[k]}{P_s[k]+P_n[k]}
$$

この倍率を使うフィルタを **Wiener フィルタ (Wiener filter)** という。
信号がノイズより十分強い周波数では $H[k]\approx1$ となって成分を残し，ノイズが十分強い周波数では $H[k]\approx0$ となって成分を除く。
両者が等しい周波数では $H[k]=0.5$ である。
白色ノイズでは $P_n[k]=\sigma^2$ である。

#### 既知のスペクトルを使った Wiener フィルタ

Wiener フィルタを使うには，$P_s$ と $P_n$ が必要である。
合成実験では，クリーン信号から $P_s[k]$ を計算でき，ノイズの $\sigma$ も分かっているので，$P_s$ と $P_n$ を既知として扱える。
実際の観測では $P_s$ と $P_n$ を観測信号から推定する必要があり，推定の誤差が復元結果に影響する。

```python
P_s = np.abs(np.fft.rfft(clean))**2 / N
P_n = np.full(f.shape, sigma**2)             # 白色ノイズのパワースペクトル
H_w = P_s / (P_s + P_n)
wiener = np.fft.irfft(H_w * Y, n=N)
print(np.round(H_w[[3, 30]], 4))  # [0.9986 0.9944]
print(np.sum(H_w > 0.01))  # 2
print(round(np.mean((wiener - clean)**2), 5))  # 0.00052
```

`np.full(f.shape, sigma**2)` は，`f` と同じ形で全要素が $\sigma^2$ の配列を返す。
3 Hz と 30 Hz では $P_s$ が $P_n$ よりはるかに大きいので，倍率はほぼ 1 になる。
クリーン信号の成分がない周波数では $P_s$ がほぼ 0 なので，倍率もほぼ 0 になり，0.01 を超える倍率は 2 つだけである。
このため，出力には 3 Hz と 30 Hz の周波数ビンに含まれるノイズしか残らず，MSE は 0.00052 まで下がる。
$P_s$ と $P_n$ がともに 0 の周波数があると，0 による割り算が起こるので注意する。

### 7. 復元結果の評価

復元方法を比べるときは，同じクリーン信号と同じノイズ（同じ seed）に対して，同じ評価指標を計算する。

```python
results = {"noisy": noisy, "moving average": ma, "low-pass": lowpass, "Wiener": wiener}
for name, estimate in results.items():
    error = estimate - clean
    mse_value = np.mean(error**2)
    snr_value = 10 * np.log10(np.sum(clean**2) / np.sum(error**2))
    print(f"{name:15s} {mse_value:.4f} {snr_value:6.2f} {np.max(np.abs(error)):.4f}")
```

```text
noisy           0.0895   6.50 0.8824
moving average  0.0227  12.46 0.4346
low-pass        0.0223  12.54 0.4874
Wiener          0.0005  28.87 0.0451
```

`results.items()` は，辞書の名前と値の組を順に返す。
`f"{name:15s}"` は文字列を 15 文字の幅で，`{mse_value:.4f}` は数値を小数点以下 4 桁で表示する書式である。
この例では，移動平均と理想低域通過フィルタの MSE はほぼ同じだが，MSE は理想低域通過フィルタの方が小さく，最大絶対誤差は移動平均の方が小さい。
このように，評価指標によって順位が入れ替わることがあるため，数値だけでなく，時間波形とスペクトルの図も合わせて確かめる。
Wiener フィルタの誤差が特に小さいのは，クリーン信号のパワースペクトル，つまり「3 Hz と 30 Hz にしか成分がない」という情報を使っているためである。
これは合成実験だから使える情報であり，この値は，スペクトルを正確に知っている場合に到達できる性能の目安と考える。
結果を保存するときは，$\sigma$，seed，窓長，遮断周波数など，結果を得た条件も一緒に記録する。

    2. `exercise/exc11_11.py` で，各 $f_c$ の理想低域通過フィルタと，窓長 9 の移動平均のそれぞれについて MSE を表示してください。
    3. 横軸を周波数 [Hz]（0〜500 Hz）として，窓長 9 の移動平均の $|H|$ と，3 つの理想低域通過フィルタの倍率 $G$ を，凡例を付けて重ねて描き，`outputs/exc11/exc11_11.png` に保存してください。
    4. 3 の図から，移動平均が 40 Hz の成分を弱める一方で，100 Hz 以上の成分を 0 にせずに通していることを確かめてください。2 と 3 の結果を使って，どちらのフィルタを使うかと，遮断周波数をどう選ぶかを，理由とともに答えてください。その際，信号の周波数について何が分かっている必要があるかにも触れてください。

5. MSE と最大絶対誤差で，復元方法の順位が変わるかを調べます。`noisy`，窓長 3，9，21 の移動平均，遮断周波数 60 Hz の理想低域通過フィルタ，基礎第6問の Wiener フィルタの 6 つの結果を比べます。

    1. 6 つの結果を MSE の小さい順に並べたときと，最大絶対誤差の小さい順に並べたときで，順位が同じになるかを予想してください。
    2. `exercise/exc11_12.py` で，各結果の MSE，最大絶対誤差，最大絶対誤差となる時刻 [s] を表示してください。結果を，列 `method,mse,max_abs_error,time_of_max` の CSV として，Python 標準ライブラリの [`csv.writer`](https://docs.python.org/ja/3/library/csv.html#csv.writer) で `outputs/exc11/exc11_12.csv` に保存してください。
    3. $0\le t<0.2$ の範囲で，窓長 3 と窓長 21 の移動平均の誤差 `estimate - clean` を重ねて描き，`outputs/exc11/exc11_12.png` に保存してください。
    4. MSE と最大絶対誤差で順位が入れ替わる組を挙げてください。その理由を，3 の図に見られる 2 つの誤差の形の違い（不規則に変動する誤差か，規則的に変動する誤差か）から説明してください。
    5. 復元結果を報告するときに，MSE だけを示した場合に何を見落とすおそれがあるかを，この結果を使って説明してください。

6. クリーン信号が分からない場合に，観測信号だけからノイズの性質を推定し，Wiener フィルタに使います。

    1. `exercise/exc11_13.md` に，クリーン信号を使わずにノイズの分散またはパワースペクトルを推定する方法を 2 つ以上書いてください。各方法には，その方法が成り立つために信号とノイズについて仮定することを添えてください。
    2. `exercise/exc11_13.py` で，観測信号のパワースペクトル $P_y[k]=|Y[k]|^2/N$ の，100 Hz 以上の周波数ビンでの平均を $\hat{\sigma}^2$ とします。発展第1問と同じ作り方の $\sigma=0.1, 0.5, 1.0$ の観測信号について，$\hat{\sigma}^2$，$\sigma^2$，`np.var(noise)` を表示してください。
    3. 発展第2問の `noisy2` についても同じ方法で $\hat{\sigma}^2$ を計算し，`noisy2 - clean` の分散と比較してください。推定が外れる理由を，2 の方法が置いている仮定から説明してください。
    4. $\sigma=0.5$ の観測信号について，$\hat{P}_s[k]=\max(P_y[k]-\alpha\hat{\sigma}^2,\ 0)$（$\alpha=1, 3, 10$）を信号のパワースペクトルの推定値とし，`wiener_filter(noisy, P_s_hat, sigma2_hat)` の MSE と，$\hat{P}_s[k]>0$ となる周波数ビンの個数を表示してください。$\max$ は `np.maximum` で計算できます。実行前に，$\alpha$ を大きくすると $\hat{P}_s[k]>0$ となる周波数ビンの個数がどう変わるかを予想してください。
    5. 4 の MSE を，基礎第6問（既知のスペクトルを使った場合）と基礎第5問の窓長 9 の移動平均の MSE と比較してください。どの $\alpha$ を選ぶかを，ノイズを残してしまう危険と，振幅の小さい信号成分まで除いてしまう危険の両方に触れて，`exercise/exc11_13.md` に書いてください。

7. フィルタを強くしすぎると信号まで失われる例を作り，スペクトルと時間波形の両方で確かめます。窓長 $M=9, 25, 101, 201$ の移動平均と，遮断周波数 20 Hz の理想低域通過フィルタを使います。

    3. 上段に $0\le t<0.4$ の時間波形（`clean` と各フィルタの出力），下段に 0〜100 Hz の振幅スペクトルを描き，`outputs/exc11/exc11_14.png` に保存してください。

    5. 窓長 201 の移動平均の MSE が `noisy` の MSE より大きくなる理由を，2 で求めた振幅と，5 Hz での $|H|$ の値から説明してください。
