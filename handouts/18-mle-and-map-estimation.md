# 第18回 最尤推定と MAP 推定

## この回の目標

尤度に基づいてパラメータを推定し，損失関数と正則化の意味を確率の観点から説明できる。

## 解説
- パラメータ $\theta$ を持つ確率分布 $p(x;\theta)$ から，データ $x_1,\ldots,x_N$ が独立に得られたとする。データが得られる確率（連続値の場合は確率密度）$\prod_i p(x_i;\theta)$ を $\theta$ の関数とみたものを **尤度 (likelihood)** という。
- 尤度を最大にする $\theta$ を求めることを **最尤推定 (maximum likelihood estimation)** という。つまり，観測されたデータが最も起こりやすくなるパラメータを選ぶ。積は値が極端に小さくなりやすいため，実際には対数をとった **対数尤度** $\sum_i \log p(x_i;\theta)$ を最大にする。
- 正規分布 $N(\mu, \sigma^2)$ に従うデータでは，$\mu$ の最尤推定値は標本平均になる。また，$\sigma$ を固定すると，負の対数尤度は定数を除いて二乗誤差の和に比例する。回帰で平均二乗誤差を損失に使うことは，誤差が正規分布に従うと仮定した最尤推定とみなせる。
- 2 クラス分類では，モデルの出力を **sigmoid 関数** $1/(1+e^{-z})$ で 0 から 1 の確率に変換し，負の対数尤度を損失にする（binary cross-entropy）。多クラス分類では **softmax 関数** で各クラスの確率に変換し，負の対数尤度を損失にする（cross-entropy）。第19回で使う回帰と分類の損失は，どちらもこの考え方に基づく。
- **MAP 推定 (maximum a posteriori estimation)** は，尤度に，パラメータについての事前の知識を表す **事前分布** を掛けた値を最大にする。パラメータが 0 に近いことを表す正規分布を事前分布にすると，損失にパラメータの二乗和を加えることになる。これは第16回の ridge 回帰や，PyTorch の optimizer の `weight_decay` に対応する。

## 演習

作業場所・保存先・説明の残し方は [共通手順](README.md#作業場所と保存先) に従ってください。以下の相対パスは，自分の作業リポジトリのルートを基準とします。

### 基礎レベル
1. `session18_gaussian_mle.py` を作成し，`rng = np.random.default_rng(0)` で `N(0.3, 1)` から 50 個の標本を生成してください。`N(mu, 1)` の `mu` を `-1` から `1` まで `0.01` 刻みで動かして観測データに対する log likelihood を計算し，`outputs/figures/session18_log_likelihood.png` に図を保存してください。log likelihood が最大となる `mu` を標本平均と比較し，最尤推定で選ばれた `mu` を項目名付きで保存してください。
2. `session18_coin.py` を作成し，コイン投げの結果 `[1, 0, 1, 1, 1, 0, 0, 1, 0, 0]`（1 が表）から，表が出る確率 $\theta$ を推定してください。モデルは $p(x;\theta)=\theta^x(1-\theta)^{1-x}$ とします。対数尤度を $\theta$ で微分して最尤推定値を手計算し，$0<\theta<1$ を細かく分けた数値計算の結果と比較してください。次に，事前分布 $p(\theta)=12\theta(1-\theta)^2$ を使った MAP 推定値を手計算と数値計算で求め，最尤推定値との違いを事前分布の形から説明してください。
3. `session18_bce.py` を作成し，logits `z = [2.0, -1.0, 0.5]` とラベル `y = [1, 0, 0]` について，sigmoid で求めた確率から負の対数尤度の平均を NumPy で計算してください。同じ値が `torch.nn.BCEWithLogitsLoss` で得られることを確認してください。

### 発展レベル
1. log likelihood を likelihood の積で直接計算した場合と比較し，log を使う理由を説明してください。基礎第1問と同じ分布から，標本数を 50，500，5000 として積を計算し，値がどうなるかを確認してください。
2. 基礎第2問の事前分布を $p(\theta)\propto\theta^{a}(1-\theta)^{2a}$ とし，$a=1, 5, 20$ の MAP 推定値を数値計算で求めてください。事前分布を強くすると推定値がどう変わるかを説明してください。
3. 第16回の基礎第3問のデータで，ridge 回帰の $\lambda$ を $0$，$0.1$，$1$ として $(a, b)$ を求めてください。$\lambda$ を大きくすると解がどう変わるかを，正規分布の事前分布の考え方と結びつけて説明してください。

## 確認ポイント
- 基礎第1問で，log likelihood が最大となる `mu` と標本平均が，刻み幅 `0.01` の範囲で一致している。
- 基礎第2問で，最尤推定値と MAP 推定値の手計算と数値計算の結果が一致している。
- 基礎第3問で，NumPy で計算した値と `BCEWithLogitsLoss` の値が一致している。
- 最尤推定と MAP 推定の違いが，事前分布の有無と形に結びつけて説明されている。
